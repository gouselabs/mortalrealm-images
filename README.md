# MortalRealm Pinterest pins

Watermarked pin images (1000×1500) for scheduling through Metricool. These are previews only; the clean wallpapers are sold on Payhip: https://payhip.com/mortalrealmstore

- `images/`: pin images
- `pins.json`: order, board, title, description and link for each pin
- `BOARDS.md`: Pinterest boards to create

Generated by `npm run pins` in the MortalRealm website project.
